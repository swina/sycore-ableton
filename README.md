# sycore-ableton

Plans and companion material for integrating [SY.CORE](https://github.com/swina/sycore-refactor) with Ableton Live: SY.CORE as the MIDI brain of the rig (routing, hardware and software synths, generative apps, AI, sync), Live as the DAW.

The SY.CORE app code lives only in `sycore-refactor`; this repo holds what sits around Live.

| Path | What it is |
| --- | --- |
| `PIANO_INTEGRAZIONE_ABLETON.md` | Integration plan (Italian) |
| `ABLETON_INTEGRATION_PLAN.md` | Integration plan (English) |
| `paper/` | "SY.CORE Live" paper for musicians and audio engineers (IT, EN), images in `paper/assets/` |

Planned later (see §11.2 of the plan): `template/` (Live Set template), `m4l/` (Max for Live device), `bridge/` (Ableton Link / OSC bridge), `docs/`, `tools/`.
